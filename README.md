# Révisions S1

Applis de révision gratuites, installables sur Android, iPhone et ordinateur. Elles marchent hors ligne.

- **Mécanique S1** : le cours de mécanique en fiches courtes, des QCM, les exercices de TD guidés et des cartes mémoire.
  - Installer : `/cinematique-s1/installer.html`
  - Ouvrir : `/cinematique-s1/`

Appli d'étudiants, non officielle. Le contenu est une reformulation du cours et des TD de mécanique S1, complétée par les annales publiques [Epidocs/past-exams](https://github.com/Epidocs/past-exams). Pour mettre à jour l'appli, voir [`src/MAINTENANCE.md`](src/MAINTENANCE.md).
